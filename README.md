OpenStack VM Automation Script

A simple Python project that demonstrates how to create and delete virtual machines on an OpenStack cloud using the official openstack sdk

Features:

- Authenticate with Keystone using project credentials
- Automatically create multiple VMs
- Apply basic scheduling hints
- Wait for VMs to become active
- List and delete VMs programmatically

Tech Used:

- Python 3.12
- OpenStack SDK
- DevStack (local OpenStack environment)
